# Human Root of Trust

Human Root of Trust (HRT) is an open discussion project about digital identity recovery, recovery-first architecture and
personal trust systems.

## Problem

Modern digital life depends on accounts, devices, credentials and recovery mechanisms.

Most security discussions focus on preventing compromise.

This project focuses on a different question:

> How can control be recovered when compromise, loss or failure eventually happens?

## Scope

The project explores:

- Human Root of Trust
- Identity Recovery Model
- Root Capability
- Recovery-first architecture
- Vault separation
- Recovery governance
- Audit and recovery drills

## Non-goals

This repository does not contain:

- secrets
- passwords
- recovery codes
- private keys
- operational vaults

## Status
