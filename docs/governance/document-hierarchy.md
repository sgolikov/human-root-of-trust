# Иерархия документов

## Цель

Документ определяет приоритеты нормативных документов проекта Human Root of Trust и правило разрешения конфликтов между ними.

## Иерархия документов

Документы проекта имеют следующий приоритет:

1. Project Spec
2. ADR
3. Concept
4. Template
5. README

## Разрешение конфликтов

Если документы противоречат друг другу, приоритет имеет документ, расположенный выше в иерархии.

Документ более низкого уровня должен быть приведен в соответствие с документом более высокого уровня.

## Роль AGENTS.md

AGENTS.md не является нормативным документом проекта.

AGENTS.md задает правила работы AI-агентов с репозиторием и не изменяет иерархию проектных документов.

## Изменение нормативных документов

Изменения нормативных документов выполняются через Pull Request.

Изменения должны сохранять documentation-first подход, границы MVP 1.0 и recovery-first философию проекта.
