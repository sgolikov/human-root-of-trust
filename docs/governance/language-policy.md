# Языковая политика

## Канонический язык

Канонический язык проекта Human Root of Trust — русский.

Нормативные документы проекта пишутся на русском языке.

## README

README может быть двуязычным: RU + EN.

README не имеет приоритета над Project Spec, ADR, Concept и Template.

## Переводы

Переводы являются производными материалами.

При расхождении между русским текстом и переводом приоритет имеет русский текст.

## AI-агенты

Codex и другие AI-агенты должны отвечать на русском языке и писать документы на русском языке, если явно не указано иное.
