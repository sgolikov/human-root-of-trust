## 1. Цель

Создать открытый OSS-проект для описания концепции Human Root of Trust и Identity Recovery Model.

Проект предназначен для обсуждения и развития подходов к управлению цифровой идентичностью, восстановлению контроля над
аккаунтами и построению recovery-first архитектуры.

Первая версия (MVP 1.0) ограничивается документацией, концепциями и шаблонами.

## 2. Scope

В MVP входят:

- концепция Human Root of Trust;
- Root Capability;
- Identity Model;
- Vault Model;
- Recovery Model;
- Location Model;
- Audit Model;
- шаблоны документов и реестров;
- рекомендации по организации recovery-процессов.

Проект описывает принципы и архитектуру, но не конкретные реализации.

## 3. Non-goals

В MVP не входят:

- программное обеспечение;
- автоматизация восстановления;
- хранение секретов;
- хранение recovery-кодов;
- хранение ключей;
- интеграция с конкретными сервисами;
- реализация vault;
- реализация IAM;
- реализация KMS;
- разработка recovery-инструментов;
- юридические процедуры наследования;
- корпоративная безопасность.

Нормативными артефактами MVP являются:
